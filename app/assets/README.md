# Assets

Place `icon.ico` here (256×256 recommended).

The icon is used by the Inno Setup installer (`build_installer/setup.iss`)
and the Windows desktop/Start Menu shortcut.

To create an .ico file from a PNG, you can use:
- https://convertio.co/png-ico/
- ImageMagick: `magick input.png -resize 256x256 icon.ico`
