JV Measurement Software — User Documentation

Version 2.4 | Open-source J-V characterization for perovskite solar cells

Developed by Lucas Polimante — UFABC

1. Overview

JV Measurement Software is an open-source Python application for automated current density–voltage (J-V) characterisation of perovskite and other thin-film solar cells. It was developed at the Universidade Federal do ABC (UFABC) to provide a reliable, reproducible, and well-documented measurement workflow compatible with common laboratory instrumentation.

The software is designed specifically for use with the Keithley 2400 SourceMeter controlled via a GPIB-USB interface (KUSB-488B adapter). Communication uses the PyVISA library with the SCPI command set native to the Keithley 2400.

Key features

  • Measures forward and reverse J-V scans with configurable voltage range, step size, and timing
  • Calculates all standard photovoltaic parameters: Voc, Jsc, FF, PCE, Rs, Rsh
  • Calculates the Hysteresis Index (HI, %) as defined by Christians et al. (2015)
  • Supports pre-bias conditioning before the reverse scan for reproducible hysteresis measurements
  • Exports data to Excel (.xlsx) with raw J-V data and extracted parameters in a format compatible with downstream macro-based analysis
  • Persistent instrument connection: the GPIB session is kept alive across measurements (no reconnect overhead)
  • Built with Python/Tkinter — runs on Windows 10/11 without requiring MATLAB or LabVIEW

3. Driver Installation

Correct driver installation is the most common source of problems. The KUSB-488B adapter requires the KI-488 driver installed in NI command-compatible mode, plus the NI-VISA runtime. Follow the steps below in order.

⚠ Critical Warning
The KI-488 driver installs a DLL (GPIB32.DLL) with the same filename as the National Instruments DLL. Having both drivers simultaneously, or installing them in the wrong order, causes system-level DLL conflicts that silently prevent VISA from detecting any instruments. Always follow the order below and restart after each major step.
Step 1 — Clean the system (CRITICAL: do this first)
  1. Disconnect the KUSB-488B adapter from all USB ports.
  2. Open Control Panel → Programs → Uninstall a program and remove all of the following if present:
    • NI-VISA (any version)
    • NI-488.2
    • NI GPIB (any variant)
    • KI-488 (any version)
    • Keithley I/O Layer
    • KUSB-488B drivers (any entry)
  3. Open Device Manager. Under GPIB Interfaces or Universal Serial Bus controllers, check for any remaining GPIB/KUSB entries. Right-click → Uninstall device (also check "Delete the driver software for this device").
  4. Restart the PC.
Step 2 — Install the KI-488 driver (hardware DISCONNECTED)
  1. Download the KI-488 driver from tek.com/keithley → Support → Software Downloads → search "KUSB-488B".
  2. Extract the downloaded .zip archive and run setup.exe.
  3. In the InstallShield wizard, when asked to select the driver mode:
    • Select "NI command-compatible" (also labelled as "National Instruments compatible" depending on version).
    • Do not select "Keithley mode" — this mode is not compatible with PyVISA.
  4. Complete the installation, then restart the PC before connecting the cable.
Step 3 — Install NI-VISA runtime (hardware DISCONNECTED)
  1. Download NI-VISA from ni.com/visa (free; requires an NI account).
  2. Run the installer. During the component selection screen:
    • Install: NI-VISA runtime only
    • Uncheck / skip: NI-488.2, NI-DAQmx, NI Measurement Studio, and all other optional components
  3. Restart the PC after NI-VISA installation completes.
Step 4 — Connect the adapter and verify
  1. Connect the KUSB-488B to a USB port on the computer. Connect the GPIB cable to the Keithley 2400.
  2. Ensure the Keithley 2400 is powered on.
  3. Open the KI-488 Configuration Utility (Start → Keithley Instruments → KI-488 Configuration Utility). The utility should show GPIB0 in the interface list and, after scanning, should detect the Keithley 2400 at its address (typically GPIB address 21, as set on the instrument front panel under Menu → Communication → GPIB Address).
  4. In the KI-488 Diagnostic Tool (within the same utility), send the command *IDN? to the detected instrument. The response should be: 
    KEITHLEY INSTRUMENTS INC.,MODEL 2400,xxxxxxx,C32 ...
  5. If the above succeeds, the driver is correctly installed. The VISA resource address will be in the format GPIB0::21::INSTR.

4. Software Installation

  1. Install Python 3.9 or higher from python.org. During installation, check the option "Add Python to PATH". Use the 64-bit installer.
  2. Open a terminal (Command Prompt or PowerShell) in the project folder: 
    cd "path\to\jv-measurement"
  3. Install all required Python packages: 
    pip install pyvisa numpy matplotlib xlsxwriter playsound
    If playsound fails to install (known build issue on some Python versions), the software will fall back to a winsound.Beep tone — this is not a critical dependency.
  4. Launch the software: 
    python main.py
    The main window should open. If you see an error about missing modules, re-run the pip install command above.
ℹ Note
The software stores no user data outside the project folder. No installation step writes to the Windows Registry. To remove the software, simply delete the project folder.

5. Connecting the Instrument

Software connection workflow

  1. Launch the software (python main.py).
  2. In the menu bar, go to Instrument → Connect…
  3. The Connect Instrument dialog opens and automatically scans all VISA resources available on the system. Each resource is queried with the SCPI command *IDN? to identify the connected device.
  4. Select the Keithley 2400 entry from the list (address format: GPIB0::21::INSTR). Confirm the identification string shows "KEITHLEY".
  5. Click ✔ Connect. The dialog closes and the status banner at the top of the main window changes from a warning to the instrument model string.
  6. The connection is persistent for the entire session — the GPIB session stays open between measurements, eliminating reconnect overhead. The Start Measurement button becomes enabled.
  7. To disconnect: Instrument → Disconnect. This sends :OUTP OFF and closes the VISA session safely.
INSERT IMAGE: instrument connection dialog showing Keithley detected at GPIB0::21::INSTR

Physical wiring: 2-wire vs. 4-wire connection

2-wire (default)

In 2-wire mode, two terminals of the Keithley carry both the source current and the sense voltage. Connect as follows:

  • Force HI (red) → counter-electrode (Au or Ag back contact)
  • Force LO (black) → transparent front electrode (FTO or ITO, the photoanode side)

In this mode, the resistance of the measurement cables, probes, and contact pads is included in the voltage reading. For typical laboratory setups with short cables, this error is small (<1 Ω total), but it does affect Rs accuracy.

4-wire (Kelvin sensing)

In 4-wire (remote sensing) mode, two additional terminals measure the voltage directly at the device contacts, eliminating the resistance of the force cables from the measurement. Connect as follows:

  • Force HI (red) → counter-electrode
  • Force LO (black) → front electrode
  • Sense HI (orange/green) → counter-electrode contact, as close to the cell as possible
  • Sense LO (orange/green) → front electrode contact, as close to the cell as possible

Enable 4-wire sensing in the Instrument Settings panel by checking "4-Wire (Kelvin) sensing". This sends :SYST:RSEN ON to the Keithley. The improvement in Rs accuracy is typically 0.5–2 Ω·cm² depending on cable and contact quality.

Instrument status banner (top, dark background)

Displays the connection status at all times. When no instrument is connected, shows a yellow warning and the Start Measurement button is disabled. Once connected, shows the instrument identification string and VISA address in white text on the dark banner.

Sample Information panel

  • Sample Name: a text identifier for this measurement session. This string is used in the output Excel filename (e.g. D1C1_20240509_143022.xlsx). Use a consistent naming scheme (e.g. batch letter + cell number: B3C2).
  • Export Folder: destination directory where Excel files are saved. Click Browse to select a folder using the system file dialog.

Measurement Parameters panel

Controls the voltage sweep range and cell area. See Section 7 for detailed descriptions.

Instrument Settings panel

Controls timing (delay per point, NPLC) and sensing mode (2-wire / 4-wire). See Section 8 for detailed descriptions.

Pre-bias Conditioning panel

Optional pre-bias before the reverse scan. See Section 9 for physical motivation and recommended settings.

Illumination Settings panel

  • Detector Power (mW): optical power reading from the calibrated reference detector placed at the sample position. Measure with an optical power meter before each sample.
  • Detector Area (cm²): active area of the reference detector. Default 1.13 cm² (Ophir PD300-UV or similar). Update this value if using a different detector.
  • Illumination (mW/cm²): calculated automatically as Power / Area. For standard 1-sun AM1.5G conditions this should read 100 mW/cm². This value is used as Pin in the PCE calculation and is saved in the Excel output.

Start / Stop buttons

  • Start Measurement: disabled until an instrument is connected and inputs are valid. Clicking opens a safety confirmation dialog before the measurement begins.
  • Stop Measurement: aborts the current measurement safely at the end of the current voltage step. The output is turned off and all controls are re-enabled.

Measurement Log

A scrollable text area that records all completed measurements with timestamps. Parameters and extracted values from each scan are appended automatically. The log persists for the entire session and can be exported as a plain-text file via File → Export Measurement Log…

J-V plot area

Updates after each completed measurement. Shows four curves: forward J (blue solid), reverse J (red solid), forward power density (blue dashed), and reverse power density (red dashed). The second y-axis on the right shows power density in mW/cm².

7. Measurement Parameters

Start Voltage (V)
Default:−0.1 V
Physical meaning:Starting point of the forward scan (low to high voltage direction).

Setting the start slightly below 0 V (e.g. −0.1 V) ensures the full Jsc plateau is captured and that the zero-crossing of the current (needed for Rsh extraction) is reliably identified. Starting exactly at 0 V can miss the true Jsc if there is a small voltage offset from contact potential or cable IR drop. A value of −0.2 V is safe for most perovskite cells. Avoid values below −0.5 V as this may cause irreversible degradation of organic transport layers.

End Voltage (V)
Default:1.05 V
Physical meaning:End point of the forward scan (and start of the reverse scan).

Should be set slightly above the expected Voc to ensure the current zero-crossing is captured within the measured range. For typical FA/MA mixed-cation perovskites under 1-sun AM1.5G, Voc is typically 1.0–1.15 V, so 1.1–1.2 V is a good end voltage. Setting this value too low will truncate the curve before Voc, making Voc extraction impossible. Setting it too high (beyond Voc + 0.3 V) may stress the cell and is unnecessary.

Step Voltage (V)
Default:0.025 V (25 mV)
Physical meaning:Voltage increment between measurement points.

Smaller steps produce a smoother curve and improve the accuracy of Jsc, Voc, and MPP extraction through better sampling density near the key features of the J-V curve. Typical recommendations for perovskites: 10–50 mV. For a range of −0.1 to 1.05 V with 25 mV steps, the scan contains 47 points per direction.

Effect on scan rate: The effective scan rate (mV/s) is determined by:

scan rate (mV/s) = Step (mV) / [Delay (s) + NPLC × (1/fgrid) + safety margin (s)]

Scan rate directly affects the apparent hysteresis in perovskites — faster scans exaggerate hysteresis; slower scans approach quasi-steady-state behaviour. Always report scan rate when publishing HI values.

Cell Area (cm²)
Default:0.07 cm²
Physical meaning:Active area of the solar cell, used to convert measured current (A) to current density (mA/cm²).

This value must be measured accurately using a calibrated aperture mask or optical microscopy. A 5% error in the cell area propagates directly to a 5% error in Jsc and PCE. When using an aperture mask (recommended to avoid edge effects and shunt leakage from the cell perimeter), enter the mask opening area, not the total cell area.

Approximate scan rates for common parameter combinations (Brazil grid: 60 Hz, 1 NPLC ≈ 16.7 ms). A 20 ms internal safety margin is added per point.

8. Instrument Settings

Delay per point (ms)
Default:100 ms
SCPI command::SOUR:DEL {value}

The hardware delay set directly on the Keithley via SCPI. This is the time the instrument waits between applying the new voltage step and triggering the ADC to read the current. It is more precise and reproducible than a Python-side sleep() call because the timing is handled entirely by the instrument's internal firmware.

For silicon solar cells, 5–20 ms is typically sufficient. For perovskite solar cells, 100–500 ms is recommended due to slow ionic redistribution after each voltage step. The slow ionic response means the photocurrent takes tens to hundreds of milliseconds to stabilise after a voltage change — measuring too quickly captures a transient current, not the steady-state response, which artificially increases apparent Jsc and FF.

Additionally, the software adds a fixed 20 ms Python-side safety margin after each :SOUR:VOLT write command (before the SCPI :READ? query). This margin is not user-configurable and is separate from the Keithley hardware delay.

⚠ Note for publications
Always report the delay per point and NPLC settings when publishing J-V data on perovskite cells. The apparent PCE and HI values are scan-rate-dependent. Both values are saved automatically in the Excel output.
NPLC (Number of Power Line Cycles)
Default:1.0
Range:0.01 – 25
SCPI command::SENS:CURR:NPLC {value}

Controls the integration time of the Keithley's analogue-to-digital converter per reading. The Keithley averages the current signal over a time window of NPLC × (1/fgrid) seconds. In Brazil (60 Hz grid), 1 NPLC = 16.7 ms. Higher NPLC values average out more 60 Hz electrical noise, producing more precise current readings at the cost of slower scan speed.

  • NPLC 0.01–0.1: fastest readout, most noise; useful for studying hysteresis rate dependence where scan speed must be maximised.
  • NPLC 1.0 (default): good balance of speed and noise for illuminated J-V scans under 1-sun conditions where photocurrents are large (15–25 mA/cm²).
  • NPLC 5–10: slower but very low noise; recommended for dark J-V measurements where currents are in the nA–μA range.
  • NPLC 25: maximum integration (≈417 ms per point at 60 Hz); rarely needed for standard J-V measurements.
4-Wire (Kelvin) sensing
Default:OFF
SCPI command::SYST:RSEN ON / :SYST:RSEN OFF

When enabled, the Keithley uses separate Force terminals (to supply current) and Sense terminals (to measure voltage) via its internal circuitry. The Sense terminals draw negligible current (<1 μA), so the voltage they measure is essentially the true voltage at the cell contacts, free from the ohmic drop in the Force cables.

In 2-wire mode, if the total cable + contact resistance is 0.5 Ω and Jsc is 20 mA/cm² over 0.07 cm² (I = 1.4 mA), the cable drop is only 0.7 mV — negligible for Voc and FF. However, Rs derived from the slope near Voc will include this cable resistance and may be overestimated by 0.5–2 Ω·cm². Enable 4-wire sensing when accurate Rs values are important (e.g. when comparing transport layer conductivities).

9. Pre-bias Conditioning

What it is

Pre-bias conditioning applies a fixed forward voltage to the cell for a defined duration immediately before the reverse scan. The Keithley output is left ON at the pre-bias voltage during the conditioning period, and then the voltage sweep begins from the end voltage (Voc side) downwards.

Why it matters physically

Perovskite absorber materials (e.g. MAPbI3, FAPbI3, and mixed-cation compositions) are mixed ionic-electronic conductors. Mobile ionic species — primarily iodide vacancies (VI+), methylammonium cations (MA+), and, to a lesser extent, Pb2+ — can redistribute slowly (timescales of seconds to minutes) in response to the electric field inside the device.

If a J-V scan is performed starting from an unknown or variable ionic state, the result is irreproducible: two identical cells measured at different times of day, or after different waiting times in the dark, may show significantly different PCE and HI values because their ionic distributions differ at the start of the measurement.

Applying a pre-bias voltage slightly above Voc (forward bias) for 2–5 s drives the ions to a well-defined accumulation state at the ETL/perovskite and HTL/perovskite interfaces. Starting the reverse scan immediately after pre-bias ensures all measurements begin from the same ionic configuration, making the HI value reproducible and comparable across samples, laboratories, and publications.

Correct measurement sequence (as implemented)

  1. Forward scan — measured without pre-bias, capturing the device in its "natural" or history-dependent ionic state.
  2. Pre-bias applied — the Keithley holds the cell at the pre-bias voltage for the specified duration.
  3. Reverse scan — measured immediately after pre-bias, starting from the conditioned ionic state.
ℹ Why this order?
Applying pre-bias before the forward scan would artificially condition the ionic state of the device before measuring FS, distorting the forward-scan results and making the HI calculation physically meaningless. The forward scan should reflect the device in its unperturbed state; only the reverse scan benefits from ionic conditioning.

Parameters

Pre-bias Voltage (V)
Default:1.2 V

Should be set to 0.1–0.2 V above the expected Voc. For typical n-i-p FA/MA perovskites with Voc ~ 1.0–1.1 V, a pre-bias of 1.2 V is appropriate. Using a voltage too far above Voc (e.g. >1.5 V for a 1.1 V Voc cell) risks forward-biasing the device into degradation. Using a voltage below Voc does not fully drive ion accumulation at the interfaces.

Pre-bias Duration (s)
Default:2.0 s

Literature recommendation: 2–5 s for typical perovskites [Christians et al., 2015]. Cells with high ion concentrations or thick absorber layers may need up to 10 s for full ionic equilibration. The status bar shows a countdown during the conditioning period.

Reference: J.A. Christians, J.S. Manser, P.V. Kamat, Best Practices in Perovskite Solar Cell Efficiency Measurements, J. Phys. Chem. Lett. 6 (2015) 3808–3814. doi:10.1021/acs.jpclett.5b00289

10. Running a Measurement

  1. Turn on the Keithley 2400 and the solar simulator. Allow the lamp to warm up for at least 15–30 minutes before taking any measurements. Most Xe-arc simulators need this time to reach stable irradiance.
  2. Connect the KUSB-488B adapter to a USB port and launch the software: 
    python main.py
  3. Go to Instrument → Connect…. Select the Keithley 2400 from the list and click Connect. Confirm the status banner shows the instrument model.
  4. Enter the Sample Name and select the Export Folder.
  5. With the reference detector at the sample position (without the cell), measure the optical power using the power meter. Enter the reading in Detector Power (mW). Verify that the Illumination (mW/cm²) field shows approximately 100 mW/cm² for 1-sun AM1.5G conditions. If it reads significantly higher or lower, check lamp alignment and shutter state.
  6. Set Measurement Parameters: start/end voltage appropriate for the cell's expected Voc, step size, and cell area (from mask or microscopy).
  7. Adjust Instrument Settings: delay per point (100–200 ms for perovskites), NPLC (1.0 for standard measurements), and 4-wire sensing if needed.
  8. If performing hysteresis characterisation, enable Pre-bias Conditioning and set the voltage slightly above expected Voc and duration to 2–5 s.
  9. Place the cell under the simulator and connect the probes (Force HI to counter-electrode, Force LO to front electrode). For 4-wire: also connect the Sense terminals.
  10. Click Start Measurement. Read the safety check dialog carefully and click OK to proceed.
  11. The software executes the following sequence automatically:
    1. Resets and configures the Keithley (*RST, source function, compliance, NPLC, delay)
    2. Measures the forward scan (low V → high V)
    3. If pre-bias is enabled: applies the conditioning voltage for the specified duration
    4. Measures the reverse scan (high V → low V)
    5. Calculates Voc, Jsc, FF, PCE, Rs, Rsh, and HI for both scans
    6. Updates the J-V plot
    7. Saves the results to an Excel file in the export folder
    8. Turns the Keithley output OFF (connection remains open for the next measurement)
    9. Plays a completion beep
  12. Review the results in the Measurement Log and the J-V plot. The Excel file is available immediately in the export folder.

11. Understanding the Results

Indicators of a good cell

  • FF > 70%: the J-V curve is square-shaped, indicating low ohmic losses (small Rs) and high shunt resistance (large Rsh).
  • |HI| < 5%: forward and reverse curves nearly overlap, indicating minimal mobile ion activity or well-passivated interfaces.
  • Jsc consistent with illumination: for a 1.6 eV bandgap perovskite under 100 mW/cm², Jsc should be approximately 20–23 mA/cm².
  • Smooth, monotonic J-V curve without kinks, plateaus, or inflection points in the power-generating region.

Common problems visible in the J-V curve

ObservationLikely causeDiagnostic action
S-shaped curve (inflection point below Voc) Extraction barrier at ETL or HTL interface; energy level misalignment For n-i-p with TiO₂: try UV pretreatment or check compact TiO₂ quality. For Spiro-OMeTAD: verify doping level (LiTFSI, Co complex).
Low FF with high Rs (>10 Ω·cm²) Series resistance losses in contacts, transport layers, or TCO Check contact pressure, probe resistance, HTL conductivity. Use 4-wire sensing.
Low Rsh (<200 Ω·cm²), slope near Jsc not flat Shunting path through pinholes in perovskite layer or incomplete coverage Inspect film under microscope. Check dark J-V for large currents at V < 0.
Large hysteresis (|HI| > 20%) High mobile ion density, unpassivated interface traps, poor grain boundary passivation Compare with stabilised power output (MPP tracking). Try passivation additives.
Jsc mismatch between forward and reverse scans Charge trapping/de-trapping artefacts at short timescales Increase delay per point; verify illumination stability during measurement.

12. Photovoltaic Parameters (Theory)

Short-circuit Current Density — Jsc
Unit:mA/cm²
Typical (FA/MA perovskite):18–26 mA/cm² under AM1.5G 1-sun

The current density when V = 0. Represents the maximum photogenerated current that can be extracted from the cell. Limited by: (a) the optical bandgap of the absorber (determines the fraction of the solar spectrum that can be absorbed), (b) film thickness and absorption coefficient (incomplete absorption), and (c) carrier collection efficiency (recombination before extraction).

Extraction method: the software finds the current density value at the voltage point closest to V = 0 using currents[argmin(|voltages|)].

Open-circuit Voltage — Voc
Unit:V
Typical (FA/MA perovskite):1.0–1.2 V

The voltage at which the net current is zero: all photogenerated carriers recombine internally without flowing through the external circuit. Voc is set by the quasi-Fermi level splitting of electrons and holes in the absorber and is fundamentally limited by non-radiative recombination (trap-assisted, interface recombination). A higher Voc requires a lower dark saturation current density J0.

Extraction method: the software finds the first voltage point where the sign of the current density changes (zero-crossing detection via np.diff(np.sign(currents))).

Fill Factor — FF
Unit:% (dimensionless × 100)
Typical (FA/MA perovskite):70–85%
Formula:FF = (Vmp × Jmp) / (Voc × Jsc) × 100

A measure of the "squareness" of the J-V curve — the ratio of the actual maximum power output to the theoretical maximum power (Voc × Jsc). FF is degraded by series resistance (Rs), shunting (low Rsh), and recombination near the maximum power point. The maximum thermodynamic FF for an ideal diode is approximately 89% at room temperature.

Extraction method: argmax(voltages × currents) gives Vmp and Jmp; then FF is computed from the formula above.

Power Conversion Efficiency — PCE
Unit:%
Typical (lab-scale perovskite):15–25%
Formula:PCE = (Voc × Jsc × FF) / Pin × 100 (with FF already in %: PCE = Voc × Jsc × FF / Pin)

The fraction of incident optical power converted to electrical power. PCE extracted from a J-V scan is a dynamic value that depends on scan speed. For certified efficiency reporting, a stabilised PCE from maximum power point (MPP) tracking over 60–300 s should be used alongside the J-V scan.

Series Resistance — Rs
Unit:Ω·cm²
Typical (perovskite):1–10 Ω·cm² (lower is better)

The total ohmic resistance in series with the photovoltaic junction: TCO sheet resistance, transport layer conductivity, contact resistance, and measurement cable resistance. Rs causes a voltage drop proportional to the current, compressing the J-V curve horizontally near Voc and reducing FF.

Extraction method: linear regression of the J-V curve over n points near Voc. The slope is dJ/dV ≈ −1/Rs (in mA cm−2 V−1), so Rs = 1000 / |slope| (converted from V·cm²/mA to Ω·cm²).

Shunt Resistance — Rsh
Unit:Ω·cm²
Typical (perovskite):500–10,000 Ω·cm² (higher is better)

The effective resistance of all parallel leakage paths across the p-n junction: pinholes in the perovskite layer, grain boundary shunts, incomplete film coverage. Low Rsh allows dark current to flow even at small forward biases, tilting the J-V curve near Jsc and reducing Voc and FF.

Extraction method: linear regression of the J-V curve over n points near V = 0. The slope is dJ/dV ≈ −1/Rsh, so Rsh = 1000 / |slope|. Always reported as a positive value (physical resistance).

Hysteresis Index — HI
Unit:% (signed)
Formula:HI (%) = (PCERS − PCEFS) / PCERS × 100

Quantifies the magnitude of J-V hysteresis. Positive HI = normal hysteresis (reverse scan gives higher PCE, typical for n-i-p perovskites with TiO₂ ETL). Negative HI = inverted hysteresis (forward scan gives higher PCE, less common, associated with some p-i-n architectures). See Section 14 for detailed physics.

13. Equivalent Circuit Model

The standard single-diode model represents a solar cell as a photocurrent source in parallel with a non-ideal diode, a shunt resistance, and a series resistance. This model provides the physical basis for interpreting all extracted parameters.

INSERT IMAGE: equivalent circuit diagram with photocurrent source (Jph), diode, Rsh, and Rs labelled

Master equation

J = Jph − J0 · [exp((V + J·Rs) / (n·VT)) − 1] − (V + J·Rs) / Rsh

Where VT = kT/q ≈ 25.7 mV at 300 K is the thermal voltage, n is the ideality factor, J0 is the dark saturation current density, and all current densities are in mA/cm².

Physical meaning of each term

ParameterPhysical meaningTypical value (FA/MA perovskite)
Jph Photocurrent density generated by absorbed photons. Approximately equal to Jsc at 1-sun. 20–25 mA/cm²
J0 Dark saturation current density. Determined by non-radiative recombination rate. Lower J0 → higher Voc. J0 = Jph · exp(−Voc / n·VT) (simplified). 10−18 – 10−15 mA/cm²
n Ideality factor. n = 1: radiative (band-to-band) or bimolecular recombination. n = 2: Shockley-Read-Hall (SRH) trap-assisted recombination. n > 2 often indicates interface recombination or ionic effects. 1.3–2.0
Rs Series resistance. Causes a horizontal compression of the J-V curve, most visible near Voc where current is high. 1–10 Ω·cm²
Rsh Shunt resistance. Causes a tilt of the J-V curve near Jsc, most visible at low light intensities or in dark J-V measurements. 500–10,000 Ω·cm²

14. Hysteresis in Perovskites

What is J-V hysteresis?

In ideal inorganic solar cells — crystalline silicon, GaAs, CdTe — the J-V curve is path-independent: the forward scan (Jsc → Voc) and reverse scan (Voc → Jsc) produce identical curves at any scan speed. In perovskite solar cells, these two scan directions produce measurably different results. This phenomenon is called J-V hysteresis.

Physical origin

Perovskite absorbers (e.g. FAPbI3, MAPbI3, FA0.83MA0.17PbI3) are mixed ionic-electronic conductors. Mobile ionic defects — most importantly iodide vacancies (VI+) and interstitial ions (Ii−) — are present in concentrations of 1015–1017 cm−3 in typical solution-processed films. These species migrate in response to the electric field during the voltage sweep, with characteristic migration times of tens of milliseconds to seconds [Tress et al., 2015].

During a voltage sweep, the ionic redistribution lags behind the electronic response because ions move orders of magnitude more slowly than electrons and holes. The slow ionic motion creates a time-dependent internal field that adds to or subtracts from the applied field, resulting in scan-direction-dependent charge extraction efficiency.

Normal vs. inverted hysteresis

TypeDefinitionHI signCommon architecture
Normal (standard) Reverse scan PCE > Forward scan PCE HI > 0 (positive) n-i-p with TiO₂ or SnO₂ ETL
Inverted (anomalous) Forward scan PCE > Reverse scan PCE HI < 0 (negative) p-i-n with PEDOT:PSS or specific passivation conditions
Negligible RS ≈ FS |HI| < 2–3% Well-passivated cells; slow scans; annealed ionic profiles

How scan parameters affect hysteresis

  • Faster scans → larger apparent hysteresis. At high scan speeds, ions have less time to redistribute between voltage steps, creating a larger discrepancy between the ionic state during the RS and FS. Reported HI values are therefore only comparable between experiments performed at the same scan rate.
  • Slower scans → smaller hysteresis. As the scan rate approaches quasi-steady state (scan rate ≪ ionic relaxation rate), the J-V curve becomes path-independent. This is why slowing down the measurement (increasing delay per point) reduces HI without changing the device physics.
  • Pre-bias conditioning standardises the ionic state before the reverse scan, making HI values reproducible and comparable between sessions and laboratories.
  • Temperature increases ionic mobility, which can dramatically change both the magnitude and sign of hysteresis. Measurements above ~50°C may show very different HI values compared to room temperature.

Why hysteresis matters for reporting

Hysteresis makes it impossible to report a single "true" PCE value from a J-V scan alone. A cell with HI = 20% and PCERS = 20% has PCEFS = 16% — reporting only the reverse scan value significantly overstates the true operating efficiency.

Best practice (per ISOS consensus [Khenkin et al., 2020]):

  • Always report both forward and reverse scan parameters (Voc, Jsc, FF, PCE)
  • Report scan direction, scan speed (mV/s), and pre-bias conditions
  • Report the Hysteresis Index
  • Complement with stabilised power output (MPP tracking over ≥60 s) whenever possible

References: Christians et al., J. Phys. Chem. Lett. 2015; Tress et al., Energy Environ. Sci. 2015; Khenkin et al. (ISOS), Nat. Energy 2020.

15. Troubleshooting

❌ "No instruments found" in the connection dialog
Possible causes:
  • KUSB-488B not detected by Windows (missing or incorrect driver)
  • NI-VISA not installed, or wrong version
  • KI-488 driver installed in wrong mode (Keithley mode instead of NI-compatible)
  • Driver installation order was incorrect
Solutions:
  1. Open Device Manager. Under GPIB Interfaces or Universal Serial Bus controllers, check whether the KUSB-488B appears without a warning icon. A yellow exclamation mark indicates a driver problem.
  2. Confirm NI-VISA is installed: open NI MAX (NI Measurement & Automation Explorer); VISA resources should appear under Devices and Interfaces.
  3. If uncertain, repeat the full driver installation procedure in Section 3 (clean → KI-488 in NI-compatible mode → NI-VISA → reboot → connect).
  4. Try a different USB port (avoid USB hubs; use a port directly on the motherboard).
INSERT IMAGE: Device Manager showing KUSB-488B correctly installed under GPIB Interfaces
❌ "ERROR ID CODE +803" on Keithley 2400 front panel
Cause: Error +803 means "Not permitted with output off" — a measurement command such as :MEAS:CURR? or :READ? was received before the output was enabled with :OUTP ON. This usually happens when the Keithley is in a partially-initialised state from a previous interrupted session (e.g. Python crash).
Solution:
  1. Press the LOCAL button on the Keithley front panel to release remote control.
  2. Turn the output OFF using the front panel OPERATE/STANDBY key.
  3. In the software, use Instrument → Disconnect, then Instrument → Connect… to open a fresh session.
  4. The software's init_instrument routine sends *RST at the start of every measurement, which should prevent this error from persisting.
❌ Rsh value is very low (<100 Ω·cm²)
Possible causes: Pinholes or cracks in the perovskite layer creating a direct short-circuit path; incomplete perovskite coverage on the ETL; incorrect cell area entry (too large).
Diagnostic steps:
  1. Verify the cell area value is correct — an area that is too large will give an artificially low Rsh (in Ω·cm²).
  2. Perform a dark J-V scan (block illumination). For a shunted cell, there will be significant current at V = 0 in the dark (ideally should be near zero).
  3. Inspect the cell under a bright lamp (transillumination) or optical microscope for visible pinholes.
❌ S-shaped J-V curve (inflection point, kink below Voc)
Cause: An extraction barrier at one of the perovskite/transport layer interfaces, caused by energy level misalignment, interfacial traps, or poor charge transport layer quality. Common for TiO₂ ETL that has not been properly sintered or UV-activated.
Solutions:
  • For TiO₂ ETL: UV-ozone treatment (15–20 min) before perovskite deposition often eliminates the S-kink by filling oxygen vacancies and improving band alignment.
  • For Spiro-OMeTAD HTL: verify doping (LiTFSI and Co complex concentrations). Excess or insufficient doping shifts the HOMO and can create a barrier.
  • General: try a fresh reference cell on the same setup to confirm the problem is the device, not the measurement system.
❌ Software crashes or freezes on "Start Measurement"
Possible causes: GPIB communication timeout; instrument in an unexpected state; Python package version incompatibility; compliance current set incorrectly.
Solutions:
  1. Verify PyVISA version: pip show pyvisa — should be ≥ 1.12.
  2. Check the GPIB address on the Keithley front panel (Menu → Communication → GPIB Address). Default is 21. If changed, the VISA address in the connection dialog must match.
  3. Check that the compliance current (0.1 A hardcoded in software) is appropriate for your cell area. For a 0.07 cm² cell at Jsc ≈ 20 mA/cm², the peak current is ~1.4 mA — well within the 100 mA compliance limit.
  4. Run the software from a terminal (python main.py) to see the full Python traceback in case of an exception.
❌ Large asymmetry in Jsc between forward and reverse scans
Possible causes: Illumination instability (lamp flicker, shutter not fully open); charge trapping transients at high scan speeds causing the current at V=0 to differ between scan directions; contact artefact at the starting voltage.
Solutions:
  • Allow the solar simulator lamp more warm-up time (≥30 min).
  • Increase delay per point to 200–500 ms to let the current stabilise at each voltage step.
  • Start the forward scan slightly below 0 V (default −0.1 V) to ensure the current plateau near Jsc is properly captured before the curve rises.
